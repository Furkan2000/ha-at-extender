# ha-at-extender

Home-Assistant-Add-on, das das ALDI-TALK-Datenvolumen überwacht und unter einer Schwelle automatisch 1 GB nachbucht.
Werte und Steuerung erscheinen per MQTT als Gerät in Home Assistant.

Basiert auf [G-Chalupa/AT-Extender](https://github.com/G-Chalupa/AT-Extender).
Dokumentation: [at_extender/DOCS.md](at_extender/DOCS.md) · Projektnotizen: [CLAUDE.md](CLAUDE.md)

> ⚠️ Laut ALDI-TALK-Leistungsbeschreibung (10.3 g) ist automatisiertes Nachbuchen untersagt. Nutzung auf eigenes Risiko.
